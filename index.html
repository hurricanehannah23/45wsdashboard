Settings

Data feeds
Set the Data service URL to your Cloudflare Worker and every feed goes through it, which is how the page loads live data on GitHub Pages. Leave it empty to call the base URLs above directly.
Running through the included proxy, use /api/c2g, /api/c2c and /api/winds. Reset to defaults clears these.
Lightning
Ring hold time is how long a ring stays active after its last strike; the countdown shows time to all-clear.
Winds
Towers are split by location: Cape Canaveral SFS is east of the Banana River and south of the LC-39 area; the rest of Merritt Island is Kennedy. Towers listed here override that, and towers with no location or south of Port Canaveral go under Other.
Wind levels are set under the trend chart. An alert fires when a tower moves up a level (Sustained Advisory, Warning – Strong, Warning – Damaging), and again after the re-alert time if it stays there.
Alerts
Team settings
Export saves thresholds, rules, rings and layer choices to settings.json. Put that file next to the dashboard on GitHub Pages (or next to wxproxy.py) and every workstation starts from it. When the dashboard is opened as a plain file, use Import on each computer instead.
